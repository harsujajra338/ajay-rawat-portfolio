# Ajay Rawat — Official Premium V4

A static, Vercel-ready premium portfolio built with HTML, CSS and vanilla JavaScript.

## Why this build is different
- Uses artist-supplied photographs shared for this presentation.
- No AI-generated artwork is used in the site.
- Editorial, restrained layout instead of generic glass-card/template styling.
- English/Hindi language switch (saved in localStorage).
- Project filters and keyboard-accessible project detail dialog.
- Real photo journal with fullscreen lightbox.
- YouTube loads only after click using youtube-nocookie.
- Instagram content opens as lightweight outbound reels instead of loading Instagram's heavy embed JavaScript.
- Hero image is preloaded; below-the-fold images lazy-load.
- WebP image assets are local and optimized.
- Scroll animations use IntersectionObserver.
- Reduced-motion support.
- Responsive navigation and layouts.
- Vercel cache headers.

## Deploy to Vercel from GitHub
Upload the CONTENTS of this folder to the ROOT of the GitHub repo:
- index.html
- styles.css
- app.js
- vercel.json
- assets/

Then commit. Vercel will redeploy automatically if the repo is already connected.
